# CtrlAltDelegate hard rules for Oh My Pi

- Follow the repository-root `AGENTS.md` and controller-owned planning/execution state.
- When suitable delegation exists, the persistent main orchestrator does not implement product-code jobs.
- A worker/task result is a claim, never acceptance; run CtrlAltDelegate parent re-verification and independent review.
- For OpenAI FRONTIER routing, GPT-5.6 Sol is capped at `high`. Never use OMP generic `effort: hi` as a substitute because it may map to `xhigh` or `max`.
- Preserve job scope, exact baseline/candidate target, worker attribution and isolated-write ownership.
