# Web Product Planning and Authoritative Content — V5.7.1

## Scope

This is an optional specialization of the global skill-driven planning contract for public websites and web products. It does not make CtrlAltDelegate website-specific.

## Planning sequence

When material, plan in this dependency order:

`BUSINESS/PRODUCT INTENT → AUDIENCE/JOURNEYS → SEARCH/COMPETITOR EVIDENCE → SEARCH INTENT/PAGE PURPOSE → INFORMATION ARCHITECTURE → UX/SXO → DESIGN DIRECTION → DESIGN SYSTEM → CONTENT STRATEGY/BRIEFS → COPY → NATURALNESS/EVIDENCE/SEO/CONVERSION REVIEW → PROGRAM DESIGN → EXECUTION`

Do not invent final marketing copy before the facts, audience, page purpose and evidence needed to support it are known.

## Content mode

Ask once during discovery when public-facing content is material whether the user wants `STRUCTURE_ONLY`, `KEY_CONTENT`, `FULL_CONTENT`, or `EXISTING_CONTENT_REWRITE`. Explain that full content planning lets the coding agent implement approved copy rather than improvise it.

## Planning artifacts

When applicable use:

- `planning/seo/SEO-STRATEGY.md`
- `planning/seo/SEARCH-INTENT-MAP.yaml`
- `planning/seo/SEO-ROUTE-MATRIX.yaml`
- `planning/seo/STRUCTURED-DATA-PLAN.yaml`
- `planning/design/DESIGN-DIRECTION.yaml`
- `planning/design/DESIGN-SYSTEM.md`
- `planning/design/UX-PRINCIPLES.md`
- `planning/content/CONTENT-STRATEGY.md`
- `planning/content/VOICE-GUIDE.md`
- `planning/content/CONTENT-MANIFEST.yaml`
- `planning/content/pages/<route-or-screen>.md`

Do not create irrelevant empty ceremony. Mark non-applicable surfaces explicitly in the manifest/state rather than generating dozens of empty documents.

## Page content contract

An approved content file should record route/screen, page type, audience, user/search intent, source facts, SEO metadata when relevant, required structured-data inputs, content sections, CTA intent and review status.

`status: approved` means implementation must preserve wording and factual/CTA meaning unless a real implementation conflict requires scoped change control.

## Content quality order

When optimization goals conflict, preserve this order:

`FACTUAL/USER-SUPPLIED TRUTH → PRODUCT REQUIREMENTS → USER COMPREHENSION → SEARCH INTENT → ACCESSIBILITY → BRAND VOICE/NATURALNESS → SEO REFINEMENT → CONVERSION OPTIMIZATION`

SEO or conversion never authorizes fabricated evidence, keyword stuffing, deceptive urgency or a worse user experience.
