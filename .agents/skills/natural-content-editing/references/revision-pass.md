# Natural Content Revision Pass

Use this reference for important public-facing copy or when a first minimal edit still leaves clear generic-writing clusters.

1. Triage language, audience, register, scope and authority.
2. Extract claim/source/persona anchors that cannot drift.
3. Remove artifacts/placeholders and resolve evidence problems first.
4. Edit lexical vagueness/inflation only where clustered or harmful.
5. Improve sentence/paragraph structure and transitions from content logic rather than stock connectors.
6. Review rhythm last; do not introduce errors or forced fragments.
7. Compare anchors and meaning; if quality was already sufficient, prefer null edit.

A deterministic detector score is never the acceptance target.
