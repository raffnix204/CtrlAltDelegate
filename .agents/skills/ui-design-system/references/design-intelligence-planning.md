# Design Intelligence for Planning

Use this reference during greenfield/redesign planning when a coherent visual direction must be decided before implementation.

## Design read
Translate product type, audience, trust/conversion needs, workflow density, platform and brand constraints into an explicit direction. Compare a small number of genuinely distinct directions only when uncertainty is material.

## Planning dials
Record three 1-10 planning dials when useful:
- `visual_variance`: restrained/systematic → expressive/asymmetric;
- `motion_intensity`: static/subtle → choreography-heavy;
- `information_density`: spacious/editorial → compact/operational.

The dials are not aesthetic scores. They make trade-offs explicit and constrain later page/component decisions.

## Master plus overrides
Persist a master design system and allow page/surface overrides only for real contextual needs. Overrides inherit the master and state exactly what changes and why; they do not create parallel design languages.

## Anti-pattern filtering
Before selecting a style, name product-specific anti-patterns. Fashionable treatments such as glassmorphism, oversized heroes, neon gradients, excessive cards or complex motion are opt-in only when they improve the product objective.

## Verification
Review representative high-risk surfaces at mobile/desktop and with realistic content before scaling the direction across the product.
