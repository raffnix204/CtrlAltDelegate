# Planning-Phase UX Decision Surface

Use when product discovery is still resolving journeys, navigation or interaction states.

The UX specialist should change discovery questions, not merely review wireframes later. For each primary role/job identify trigger, shortest successful path, decisions, system feedback, recovery and completion. Surface missing empty/loading/error/offline/permission/destructive states while scope is still cheap to change.

Persist high-impact decisions in requirements/program design and page/surface UX principles. For searchable public pages, coordinate with `search-experience-optimization` so page type and information architecture satisfy both user task and current search evidence.
