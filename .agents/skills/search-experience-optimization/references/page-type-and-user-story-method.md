# Page-Type and User-Story Method

Use when search intent can materially change the planned page or workflow.

1. Define the target job/query cluster and intent uncertainty.
2. Research a representative current result set when available.
3. Classify result page types and notable result features using one consistent taxonomy.
4. Record consensus/confidence rather than treating the top result as truth.
5. Derive 3-5 evidence-linked user stories/objections only where signals support them.
6. Compare planned/actual page type, answer structure, proof, interaction and action path.
7. Change architecture/content only when the evidence and product objective justify it.
