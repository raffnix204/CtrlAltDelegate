# SEO Planning Artifact Model

Use this reference when the project needs detailed search planning before implementation.

## Search intent map
Record topic/query cluster, audience/job, intent class, evidence source, target page type, existing/planned route, funnel role, confidence and unresolved research.

## Route matrix
For each public route record page purpose, primary audience, canonical/indexability intent, source content owner, internal-link parents/children, structured-data candidates and acceptance evidence.

## Roadmap
Prioritize foundation, migration risk, high-value page/content gaps, measurement and ongoing improvement. Avoid calendar promises that assume rankings occur on a fixed schedule.
