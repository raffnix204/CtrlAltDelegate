# Chart Selection Matrix

Use when the analytical task could map to multiple visualization families.

- Trend over ordered time: line/area for continuous series; bars for discrete periods when comparison is primary.
- Category comparison/ranking: aligned bars or table with bars/sparklines.
- Distribution: histogram, density, box/violin when statistical literacy supports it.
- Relationship: scatter/bubble only when dimensions and encodings are explainable.
- Part-to-whole: stacked bars for comparison; pie/donut only for few stable parts where angle judgment is adequate.
- Funnel/flow: use when stages/transition counts are real, not as decoration.
- Exact operational lookup: table often beats chart.

Always validate units, aggregation, missing values, uncertainty, accessibility and expected cardinality.
