# Search Content Brief Contract

Use this reference when producing final or near-final public page content during planning.

A brief records: route/page type, audience, user/search intent, primary job/question, known product facts, required evidence/sources, prohibited/unverified claims, key objections, required sections, internal-link relationships, CTA intent, metadata goal, structured-data inputs, media/data needs and review status. Draft from this brief, then run naturalness, evidence, SEO/SXO and conversion review before setting content `approved`.
