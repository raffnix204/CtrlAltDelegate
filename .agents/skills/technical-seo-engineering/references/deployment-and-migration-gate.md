# Technical SEO Deployment and Migration Gate

Use this reference for launches, domain/path changes, framework/rendering migrations or other high-blast-radius web releases.

Before release capture representative status, canonical, robots, sitemap, title/H1, rendered-content and structured-data baselines. Maintain explicit old-to-new mappings where URLs move. After release recrawl old and new routes, verify permanent redirects where intended, no redirect loops/chains, correct final canonical/indexability, no accidental staging noindex/robots rules, and updated internal links/sitemaps. Record any intentional deviations.
